# v0.7.1 macOS 26 启动崩溃修复

> 日期：2026-09-09

## 现象

双击 `dist/MenuBarOrganizer.app` 后没有出现菜单栏触发器，进程启动约 1–2 秒即退出。

## 根因

崩溃报告显示 `MenuBarHidingEngine.boundaryFrame(_:)` 将 `NSWindow.windowNumber` 直接转换为 `CGWindowID` 时触发：

`Swift runtime failure: Not enough bits to represent the passed value`

v0.7.0 新增启动自动恢复布局后，这条此前只在手动应用时运行的路径会在启动阶段自动执行，因此问题表现为应用无法打开。

## 修复

- 使用 `UInt32(exactly:)` 校验窗口编号。
- 拒绝负数、0 及超出 `CGWindowID` 范围的编号，不再触发运行时陷阱。
- 为转换逻辑增加边界测试。

## 验证

- Debug 构建与测试目标编译通过。
- Release 通用二进制构建和签名验证通过。
- 使用 Finder/LaunchServices 路径实际启动 `dist/MenuBarOrganizer.app`。
- 进程持续运行超过一分钟。
- 修复后未产生新的崩溃报告。
