> 日期：2026-09-07

## 本轮目标

建立独立、可构建的原生 macOS 工程，先验证无需高级权限的普通收起模式。

## 已实现

- 菜单栏切换状态项；
- 收起区域分隔项；
- 点击收起和展开；
- 右键菜单与基础诊断窗口；
- 根据最宽显示器计算收起占位长度；
- 显示器热插拔后重新计算；
- 应用退出前主动恢复展开状态；
- 收起长度的单元测试。

### 首次启动问题与修复

第一次实机启动时进程存在，但菜单栏没有出现控制项。顶部截图确认不是图标被刘海挤走，而是原始 `@main AppDelegate` 入口没有把代理实例注册给 `NSApplication`，导致启动回调没有执行。

现已改为显式入口：创建 `NSApplication.shared`、持有并注册 `AppDelegate`、启动事件循环。技术原型阶段每次启动都会主动显示设置与诊断窗口，确保即使菜单栏空间不足，用户也能确认应用已运行并退出。

修复后已确认设置与诊断窗口正常出现，菜单栏双箭头位于现有第三方状态项左侧；自动化执行一次收起和展开后，界面状态正确切换，最终恢复为展开。分隔线同时改为适配明暗菜单栏的 SF Symbols 模板图标，提高可见性。

用户随后提供的真实截图确认菜单栏控制项仍未显示。由于原型同时隐藏了 Dock 图标，用户无法主动重新打开窗口。`v0.1.1 Alpha` 已改为普通 macOS 应用：保留 Dock 与 Command-Tab 入口，再次打开应用或点击 Dock 图标都会显示设置窗口；两个状态项也显式设置为可见。菜单栏入口稳定前不再启用纯后台模式。

## 使用方式

1. 启动应用后，菜单栏出现竖线和双箭头。
2. 按住 Command，把需要收起的其他应用图标拖到竖线左侧。
3. 点击双箭头收起或展开。
4. 右键双箭头打开设置与诊断或退出。
