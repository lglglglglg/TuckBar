# v0.4.1 第二行菜单栏视觉重构

## 产品形态纠正

隐藏项目入口不是应用启动器，也不是带标题的卡片列表。它应当表现为系统菜单栏的临时第二行：紧贴菜单栏，仅承载原始状态项，视觉密度和点击习惯与第一行一致。

## 本次改动

- 删除“隐藏的菜单栏项目”标题、项目数量、应用名称和说明文字。
- 删除每个项目外层的常驻大卡片。
- 面板高度由约 156 pt 缩减为 46 pt。
- 面板宽度根据原始状态项宽度动态计算，不再固定为 560 pt。
- 图标高度统一为 22 pt，同时保留文本型、进度型状态项的横向宽度。
- 使用 macOS 原生材质、10 pt 圆角和 0.5 pt 轻描边。
- 只有鼠标悬停时才显示轻量点击反馈。
- 面板与菜单栏间距缩小到 5 pt，并继续以工具入口为锚点定位。

## 保留原则

- 面板只显示原始状态项快照，不显示所属应用图标。
- 无屏幕捕获权限时仍使用明确占位符，不制造“看似正确”的假图标。
- 项目名称只作为鼠标悬停提示和辅助功能文本，不占据面板空间。
