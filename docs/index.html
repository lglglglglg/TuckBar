精美、轻量、可靠的
macOS 菜单栏收纳利器

专为刘海屏及图标较多的 Mac 用户精心设计。让菜单栏恢复清爽，同时随心所欲呼出与操作每一个应用。

直接下载 DMG 安装包 (.dmg) 所有版本与源码 (Releases)
支持 macOS 14.0 (Sonoma) 及更高版本 · 原生支持 Apple 芯片与 Intel 架构 · 完全开源免费
🖥
双展现形态
支持顶栏原生展开折叠（经典稳定），以及第二行悬浮胶囊浮岛（适配刘海屏无缝避障），随心切换。
🖐
多维手势与触感
除左键点击外，支持菜单栏滚轮/双指滑动呼出、悬停触发、全局快捷键 ⌥ B，并配有多级细腻触觉反馈。
🎯
100% 真实原生触发
拒绝死板截图冒充。直接调用宿主原生状态项，点击准确唤出真实菜单、状态弹窗与后台控制面板。
🟢
App 运行状态指示
智能扫描后台真实运行状态，在偏好设置列表中以翠绿色小圆点标明活跃应用，一览无余。
📦
三层精细化分类
提供【常显】、【已收纳】与【始终隐藏】三层分区。支持搜索筛选、一键批量移入收纳及浮窗右键便捷管理。
🔒
零网络 · 绝对隐私
完全本地离线运行。无网络请求、无用户追踪埋点，不保存桌面录屏与截图，所有数据只存留在本机。

丝滑交互方式

多种触发方式，总有一种顺手适合你的工作流

动作 操作方式
展开 / 收起菜单栏 单击状态栏图标，或使用全局快捷键 ⌥ Option + B
手势展开 / 收起 光标停留在菜单栏区域，向上/向左滚动展开，向下/向右滚动收起
悬停查看 鼠标移动至 TuckBar 图标上方微停即可自动展开
浮岛快捷管理 在浮岛中右键任意收纳图标，即可快速改设为“常显”或“在访达中显示”
打开偏好设置 右键图标选择“偏好设置…”，或按下快捷键 ⌘ Command + ,
