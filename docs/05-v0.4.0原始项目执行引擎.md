# v0.4.0 原始菜单栏项目执行引擎

## 本阶段目标

让“隐藏列表”真正作用于系统菜单栏中的原始状态项，而不是只改变设置页或面板内容。

## 执行方式

- 工具在自己的可见菜单栏入口左侧创建一个宽度为 1 pt 的透明内部边界，不绘制分割线。
- 用户点击“应用隐藏设置”后，执行引擎使用 macOS 原生的 Command 拖动语义，将选中的原始状态项移到内部边界左侧。
- 收起时扩大透明边界的占位宽度，使边界左侧项目退出当前屏幕的可见菜单栏空间；工具自己的入口仍保留在右侧。
- 点击“暂时展开全部”、显示器配置变化或应用退出时，边界恢复为 1 pt，原始项目重新可见。
- 打开隐藏项目面板时先临时展开并重新识别项目，随后抓取原始状态快照；点击面板项目时再次临时展开并把点击转发给当前原始项目。

## 身份与恢复

- 窗口 ID 只用于本次进程内定位，不能持久化。
- 持久身份由来源 Bundle ID 与该应用 Accessibility extras menu 中的项目序号组成。
- 同一应用存在多个状态项时可以分别选择，不再因为拖动改变屏幕顺序而互相混淆。
- 取消勾选后再次应用设置，执行引擎会把位于隐藏边界左侧的项目移回右侧可见区。

## 安全边界

- 移动原始项目需要辅助功能权限；无权限时不会发送鼠标事件。
- 屏幕录制只用于获取原始图标像素快照，不参与移动和收起，也不会在后台反复请求。
- 某些系统项目或应用可能禁止 Command 拖动；界面会报告实际移动数量，不假装成功。
- 本阶段不会启动时自动重排菜单栏，只有用户明确点击“应用隐藏设置”才执行。
