# v0.8.8 唤醒后收起状态恢复

## 问题

锁屏、睡眠或显示器参数变化后，macOS 可能重建状态栏项目并重置 TuckBar 的透明边界长度。旧逻辑只执行“展开全部”，没有在菜单栏服务稳定后重新应用隐藏布局；悬停监听还会在恢复期间提前打开聚合条，导致用户看到部分图标重新出现或状态反复。

## 修复

- 监听 `NSWorkspace.didWakeNotification` 和 `screensDidWakeNotification`。
- 显示器参数变化不再永久展开，而是进入同一个延迟恢复队列。
- 恢复队列会取消悬停/面板任务、关闭聚合条、先收起边界，等待菜单栏服务稳定后重新扫描并应用隐藏配置。
- 恢复期间屏蔽悬停触发，避免中间状态被用户看到。
- 新的唤醒事件会取消旧队列，避免重复并发应用布局。
