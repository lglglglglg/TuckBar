# v0.8.7 macOS 应用图标缓存修复

## 问题

v0.8.6 直接把 `TuckBarBrand.png` 配置为 `CFBundleIconFile`。设置页能够读取这张图片，但 Dock、Finder 与应用程序切换器可能继续显示旧版本的三横线图标，因为 macOS 的应用图标链路优先使用标准应用图标资产及其缓存。

## 修复

- 以最终确认的无尖角 TuckBar 品牌图为唯一源图。
- 新增标准 `Assets.xcassets/AppIcon.appiconset`，包含 macOS 需要的 16–1024 像素全部倍率。
- 使用 `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon` 让 Xcode 生成应用图标资源。
- `Info.plist` 改用 `CFBundleIconName = AppIcon`，不再直接把普通 PNG 当作应用图标。
- 版本提升至 0.8.7，帮助 Launch Services 识别图标资源已经更新。

菜单栏模板图标仍由 `Brand.swift` 独立绘制；应用图标和设置页品牌图则共同使用同一张无尖角源图，避免视觉不一致。
