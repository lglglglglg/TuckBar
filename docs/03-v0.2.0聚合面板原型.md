# v0.2.0–0.2.4 聚合面板原型

> 日期：2026-09-07  
> 用途：验证菜单栏项目发现、集中展示与点击代理链路

## 本阶段完成

- 点击菜单栏双箭头时扫描当前屏幕上的可见菜单栏状态项。
- 在菜单栏下方弹出横向聚合面板，显示项目数量、所属应用图标和名称。
- 设置窗口增加“打开聚合面板”入口和识别数量诊断。
- v0.2.1 增加屏幕录制/辅助功能权限状态与主动授权入口，避免未授权时表现为无响应。
- v0.2.2 验证状态项进程 PID 回退方案；macOS 26 实测所有项目均由控制中心托管，无法据此区分第三方项目。
- v0.2.3 固定应用路径与指定签名规则，并在应用重新激活时复查权限，避免每次测试构建更换 TCC 身份。
- v0.2.4 增加 macOS 26 降级发现：名称被隐私系统隐藏时仍按窗口几何展示和代理状态项，不再返回空面板。
- 聚合面板项目支持点击代理；首次点击时按 macOS 规则申请辅助功能权限。
- 保留原生分隔线收起模式，兼容可通过 Command 拖动的状态项。

## 当前机器验证依据

取得名称元数据时，窗口服务器能返回多个第三方状态项，包括 Codex、iCopy、iShot、Shadowrocket、搜狗输入法、超级右键和 Cockpit Tools。本应用自己的状态项会被过滤；未取得名称时只能按窗口几何降级发现，因此结果可能暂时包含系统项或多显示器副本。

## 已知限制

- 当前显示的是所属应用图标，还不是菜单栏项目的实时像素快照，因此不能表达流量、数字、电量等动态状态。
- 同一应用同时创建多个状态项时，当前原型只保留一个代表项。
- 扫描范围是当前可见状态项；已经被刘海挤出可见区域的项目仍需在后续阶段通过更完整的捕获和配置机制处理。
- 点击代理依赖辅助功能权限。授权是用户主动行为，原型不会自动修改系统权限。
- 尚未实现拖拽排序、常显/隐藏分组、搜索、悬停唤出和登录启动。

## 下一阶段建议

先把“实时菜单栏图标快照 + 项目身份持久化 + 点击后定位原项目”做稳定，再进入拖拽分组和正式视觉设计。这样能优先验证产品最关键、也是 iBar/Ice 类工具技术风险最高的闭环。
